Copy this structure into an authored proposal outside installed package directories; replace prompts with observed evidence and actual reasoning. This template is not a completed proposal or a reviewer response.

Give the output its own complete YAML `type: Reference`, `title` and `description`; retain this template as a reference and replace prompts with actual evidence. Add links only to existing sources.

# Problem and request source

Identify the customer request, source identity, retained text and provenance. Separate supplied synthetic input from a live source read and record missing integrations.

# Proposed behavior and acceptance criteria

Describe the user interaction and artifact contract concretely. Enumerate required checks, including edge cases and privacy behavior. State any assumptions.

# Scope, exclusions and decisions

Resolve the proposed format and supported data. List exclusions and decisions with their rationale; identify unresolved questions that need review.

# Review target

Identify the required reviewer and stable proposal revision/hash. Record that review is pending until actual input arrives. Preserve the review input separately and link it after receipt.
