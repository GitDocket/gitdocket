This index starts with no completed deliveries. During a Product delivery invocation, create an ordinary Markdown record under this directory and add a link here. The record should identify the request, current observed phase, retained proposal, review input and revision, task/commit evidence, verification and next action. Update the authored links here as evidence appears; let the Docket CLI own the generated bundle index.

For a later feature or fresh-session continuation, follow the relevant record rather than guessing the current phase from task status. Missing review, failed checks and unavailable required capabilities remain unresolved. Do not insert predicted outcomes or prewritten agent replies.
