Create a separate authored record and link it from the delivery index. This template contains no observed phase or successful outcome.

# Request and current phase

Identify the request and state the current observed phase, what established it and the next unresolved action. Keep feature progress separate from individual task status.

# Evidence chain

Link the retained request, proposal and stable revision, actual review input and provenance, accepted decisions, tracked epic/tasks when authorized, commits, verification and handoff as each becomes available. Distinguish absence from completion.

# Assistance and limitations

Record manual setup, supplied review inputs, agent host, continuation assistance, missing capabilities and unrun checks. Record external action references only for actual observed actions.
