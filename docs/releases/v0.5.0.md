# GitDocket 0.5.0

GitDocket 0.5.0 adds Cursor as a first-class harness, restores and expands opt-in local usage telemetry, and ships the compact homepage install control. It preserves the published 0.4.1, 0.4.0, 0.3.1, 0.3.0, 0.2.1 and 0.1.1 workflow merge bases.

## Cursor beside Claude and Codex

- Initialize Cursor with `docket init --agent cursor`. That writes `.cursor/skills/docket-*/SKILL.md` pointers and, when `docket-mcp` is on PATH, registers `docket` in `.cursor/mcp.json` without clobbering Claude, Codex, or an existing custom Cursor MCP entry.
- Combined `--agent cursor --agent claude --agent codex` installs remain additive. Cursor does not rewrite `.mcp.json`, Claude settings, or Codex TOML.
- Pickup and epic-manager titles use Cursor's `rename_chat` on the calling conversation. Epic supervision on Cursor stays serial in that session; isolated worker/worktree orchestration is not claimed.
- After init writes a new project server, enable it once in Customize → MCPs (Command Palette: Open MCPs). Init cannot complete that host approval.
- `docket upgrade` regenerates stale marked Cursor skill stubs, skips hand-authored Cursor files, and does not rewrite `.cursor/mcp.json`.

Public install and harness docs name Cursor beside Claude and Codex. Canonical workflows stay host-neutral; Cursor tool names stay in the adapter layer and generated skills.

## Installation

```sh
brew install gitdocket/tap/gitdocket
docket --version
docket-mcp --version
```

The project-maintained formula installs standalone CLI/MCP executables, embedded browser resources and retained upgrade history. No separate Bun, Node or npm installation is needed. Release qualification combines Ubuntu 24.04 ARM64/x64 checks in Linux-only GitHub Actions with local Mac ARM64 and Rosetta-assisted Intel checks; receipts record the actual Mac OS and assistance. The formula supports macOS 15+ and Homebrew-compatible glibc Linux on those architectures. Windows is not supported.

Node 22+ users can instead run `npm install -g --include=optional @gitdocket/cli@0.5.0 @gitdocket/mcp@0.5.0`. The existing npm names launch exact-version platform packages containing the same binaries as Homebrew. The core/web libraries remain Bun-based. Source development and the Beacon example app still require Bun.

Use your package manager to update the executables. In each project, review `docket upgrade --dry-run --json` before applying `docket upgrade` and resolving any reported conflicts or retained differences. Package installation, updating and removal preserve project bundles; they do not reconcile project instructions automatically. If switching from npm/Bun, inspect command precedence and custom MCP paths using the [migration guide](../homebrew.md#moving-from-npm-or-bun).

All eight coordinated npm packages use 0.5.0. Claude adapters are generated; Claude behavior remains unqualified where authentication is unavailable. Isolated Cursor worker orchestration remains out of scope.
