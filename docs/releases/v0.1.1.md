# GitDocket 0.1.1

## Highlights

- Coordinates sequential task and epic IDs across linked Git worktrees,
  including uncommitted sibling-worktree concepts, while retaining explicit
  duplicate recovery for separate clones.
- Adds bounded, provenance-bearing evidence for task-linked commits on local
  branches and worktrees without letting another checkout override canonical
  status, readiness, or authored project context.
- Makes opt-in Serve commits resilient to concurrent `HEAD` and index changes
  through isolated commit trees, repository-operation refusal, hooks, signing,
  and compare-and-swap publication.
- Adds deterministic candidate planning, fail-closed public staging, and an
  exact local-tarball product smoke before publication.
- Adds approval-gated, tokenless npm publication under a holding tag with safe
  recovery for partial package and dist-tag states.
- Completes a coherent registry release with verified provenance, a
  registry-only product smoke, and a first-class GitHub Release receipt.
