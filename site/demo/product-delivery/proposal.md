# Proposed export behavior

Add one visible, enabled Export button to Beacon’s existing local interface. Activating it downloads the current saved bookmark collection as a single local JSON file named `beacon-bookmarks.json`. The export is generated entirely in the browser without fetching stored URLs or sending bookmark data over the network.
